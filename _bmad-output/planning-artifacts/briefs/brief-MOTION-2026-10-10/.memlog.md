- (decision) Core mechanic: friends must match on the SAME habit (not freeform), so leaderboard comparisons are apples-to-apples. Resolves the fairness problem without a normalization/points system.
- (decision) v1 integrations: Apple HealthKit + Whoop API (pilot scale). Screen Time explicitly deferred — Apple's API (and every third-party screen-time app, e.g. Opal) sandboxes data with no export path, confirmed via research.
- (decision) Differentiator vs. Pact (closest comparable): automatic verification via Health/Whoop vs. Pact's manual photo proof.
- (decision) Social hook: WhatsApp-linked sharing/trash-talk flow into the group chat friends already use.
